# 🗺️ ROADMAP - Pelada da Fé

> Planejamento oficial do projeto.

---

# 📌 Visão do Projeto

Desenvolver um sistema web e PWA para gerenciamento de peladas de futebol, permitindo:

- Cadastro de jogadores
- Organização das peladas
- Sorteio automático de equipes
- Controle de partidas
- Ranking de artilharia
- Estatísticas
- Dashboard
- Instalação como aplicativo (PWA)

---
