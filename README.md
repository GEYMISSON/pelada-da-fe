# ⚽ Pelada da Fé

Sistema completo para gerenciamento de peladas de futebol.

## Funcionalidades

- Cadastro de jogadores
- Cadastro de peladas
- Sorteio inteligente de times
- Registro de partidas
- Registro de gols
- Artilharia do dia
- Artilharia geral
- Estatísticas
- Histórico
- PWA (Aplicativo para celular)

## Tecnologias

- Node.js
- Express
- MongoDB Atlas
- Mongoose
- Bootstrap 5
- JavaScript
- HTML5
- CSS3
