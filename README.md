# 📖 Sobre

O **Pelada da Fé** nasceu para resolver um problema comum em grupos de futebol:

- Quem joga em qual time?
- Como fazer um sorteio equilibrado?
- Quem é o artilheiro?
- Quantos jogos cada jogador participou?
- Quem foi campeão mais vezes?

O sistema centraliza todas essas informações em um único lugar.

# ⚙ Instalação

```bash
git clone https://github.com/GEYMISSON/pelada-da-fe.git
```

```bash
cd pelada-da-fe
```

```bash
npm install
```

Criar

```text
.env
```

```env
PORT=3000

MONGO_URI=sua_conexao
```

Executar

```bash
npm run dev
```

Abrir

```
http://localhost:3000
```
